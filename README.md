# ドラム譜メーカー

動画ファイルを読み込み、演奏されているドラムのリズムを自動解析してドラム譜（ドラムタブ）を生成する Web アプリです。サーバーへのアップロードは行わず、すべてブラウザ内 (Web Audio API) で処理します。

## 使い方

1. 動画ファイル（mp4 / webm / mov など）をドロップまたは選択
2. 「解析する」を押すと、音声トラックからハイハット・スネア・バスドラムのオンセット（打点）を検出
3. BPM は自動検出されますが、手入力やタップテンポでも調整可能
4. 拍子・音符の細かさ・各パートの検出感度を調整すると譜面が再計算されます
5. 譜面のマスはクリックで手動修正、ダブルクリックで動画をその位置にシーク
6. 「印刷 / PDF保存」でそのまま印刷・PDF化できます

## 仕組み

- `src/lib/audioDecode.ts`: 動画ファイルから `AudioBuffer` をデコード
- `src/lib/onsetDetection.ts`: 3バンド（低域=キック / 中域=スネア / 高域=ハイハット）にフィルタリングした後、整流・平滑化してエンベロープを抽出し、適応的閾値でピーク（打点）を検出
- `src/lib/tempo.ts`: 検出した打点間隔のヒストグラムから BPM を推定
- `src/lib/quantize.ts`: 打点を BPM・拍子・音符細かさに基づくグリッドへスナップ
- `src/components/DrumSheet.tsx`: グリッドをドラムタブとして描画し、動画再生位置に合わせて再生カーソルを表示

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック + 本番ビルド
npm run lint     # oxlint
```

## 制限事項

- 周波数帯域による簡易的な楽器分類のため、ノイズ成分の多い音源では誤検出（クロストーク）が発生することがあります。感度スライダーやマス目の手動編集で補正してください。
- ブラウザの `decodeAudioData` が対応していないコーデックの動画は読み込めません（Chromium 系ブラウザではライセンスの都合で mp4/AAC を再生・デコードできない場合があります。その場合は webm 等をお試しください）。
